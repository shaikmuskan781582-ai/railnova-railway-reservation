ENGINEERING & ARCHITECTURE

Core Capabilities of the C++ Reservation Engine

Built with object-oriented C++, native Windows Winsock2 networking, and persistent storage.

High-Performance C++ Backend

Native multi-threaded Winsock2 HTTP server listening on port 8080 with zero third-party framework overhead.

Atomic Seat Validation

Windows CRITICAL_SECTION mutex locks ensure that multiple concurrent browser requests cannot overbook train capacity.

50% Child Discount

Passengers under 12 automatically receive a 50% fare reduction calculated and applied by backend business logic.

Persistent File Storage

Every booking and cancellation is persisted to tickets.txt in pipe-delimited format, surviving server restarts seamlessly.

80% Refund Cancellation

Cancellations refund 80% of total fare (20% fee) and automatically restore allocated seats back to the fleet.

Whitespace & Case Tolerant

Route queries are automatically trimmed and normalized so user variations like " delhi " match correctly.
